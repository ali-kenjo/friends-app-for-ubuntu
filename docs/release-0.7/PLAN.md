## 2. Robot engine and surroundings
- [x] **A.1 Expressions & Face**: Expand moods from 14 to 30 (`love`, `embarrassed`, `mischievous`, `bored`, `determined`, `dreamy`, `grumpy`, `startled`, `relieved`, `smug`, `worried`, `laughing_hard`, `winking`, `shy_smile`, `inspired`, `playful`) and gestures from 13 to 40 (`wink`, `blow_kiss`, `facepalm`, `clap`, `thumbs_up`, `fist_pump`, `dance_groove`, `dance_spin`, `dance_robot`, `shiver`, `stretch`, `yawn`, `sneeze`, `hiccup`, `hug`, `high_five`, `bow`, `salute`, `big_shrug`, `chin_on_hand`, `scratch_head`, `big_wave`, `royal_wave`, `peek`, `hide`, `dizzy`, `whistle`, `drum_roll`, `flex`); add phoneme-like lip-sync formants (`bands.mjs`), adjustable blink rate/style, pupil behavior, eye effects (`hearts`, `stars`, `spirals`, `tears`, `sparkles`), blush levels, and cheek/forehead indicator lights; keep synced with `server/robot.js` and `server/tools.js` (including `ESSENTIAL` tools for local models)
- [x] **A.2 Idle Life Scheduler**: Weighted idle-behavior scheduler so the robot is never frozen (breathing/hover variance, looking around room, inspecting props, stretching, yawning, humming, fidgeting, tinkering, reading a book, watering plant, sipping drink, checking tablet, napping when idle long with gentle wake-up on return) plus context reactions (sleepy at night, tapping fingers while reply is slow, pacing while thinking long, peeking while user types)
- [x] **A.3 Personality & Behaviors Studio Tab**: Per-character behavior settings (`energy`, `curiosity`, `playfulness`, `clumsiness`, `shyness`, `expressiveness`, `talkMotion`, `roamRange`, `personalSpace`, `reactionStrength`), individual toggles and frequencies for every idle behavior, and behavior presets (`calm`, `bubbly`, `dramatic`, `sleepy`, `mischievous`)
- [x] **A.4 Synthesized Robot Sound**: Optional WebAudio robot sound synthesizer (`src/js/robot/sound.js`, off by default) for blips, hums, servo whirs, giggles, sighs, chimes, and prop ambience; volume, pitch per character, category switches, and optional mix-into-recording toggle (`#voice-rec-robot-sound`)
- [x] **A.5 Physical Interaction**: Named touch zones on the 3D robot (`head` pat, `cheek` poke, `arm` shake & high five, `belly` tap), bounded room dragging that springs back smoothly, optional `eyesFollowCursor`, and escalating multi-touch reactions
- [x] **A.6 Event Reactions**: Configurable per-event reaction switches (`mission`, `reminder`, `notifications` for Telegram/Reddit looking at tablet/phone prop, `taskDone`, `habitStreak`, `timeOfDay`, `userReturn`) wired to app lifecycle and custom events
- [x] **A.7 Body Customization & Looks**: Expand body, head, top (ears/fins), hand, hover, eye, and mouth types; add material finishes (`felt`, `clay`, `glass`, `wood`, `brushed_metal`, `holographic`, `glow_in_dark`), body patterns & decals, name badge text, held items slot (`pen`, `mug`, `wrench`, `wand`, `book`, `tablet`, `microphone`, `flower`, `balloon`, etc.), ~60 new accessories across slots, randomize button per Studio tab, color palettes, >= 10 new built-in looks, and versioned `.robot-look.json` export/import
- [x] **B.8 New Places**: Add >= 12 new 3D places (`bedroom`, `kitchen`, `library`, `greenhouse`, `rooftop`, `workshop`, `cabin`, `seaside`, `campfire`, `cafe`, `arcade`, `observatory`, `tatami`, `treehouse`, `underwater`, `train`, `spaceship`, `attic`), each with distinct mood, lighting, and ambience
- [x] **B.9 Rich Procedural Props**: Give every non-flat place (old and new) >= 15 distinct, individually switchable procedural props, many animated (kettle steam, crackling fire, real-time clock, swaying curtains/plants, breathing sleeping cat, fish tank, spinning record player, lava lamp, TV/screens, rain on window, birds outside, dust in light), merged/instanced and created lazily
- [x] **B.10 Interactive Props & AI Spatial Tools**: Click/tap props in the 3D scene to toggle/use them (lamp on/off, radio/record player ambience, blinds, fireplace, TV, water plant, pat pet); robot uses props autonomously and via new AI tools `robot_use_prop`, `robot_go_to`, `robot_look_at` (including in `ESSENTIAL` tool set)
- [x] **B.11 Room Companions**: Switchable animated room companions (`cat`, `drone`, `goldfish`, `plant_sprite`, `vacuum`)
- [x] **B.12 Time, Weather & Seasons**: Real-clock or manual lighting time, window view reflecting time of day and Weather connector state (when enabled and not in Private mode), and selectable or date-automatic seasonal/festival sets (`winter`, `autumn`, `spring`, `summer`, `christmas`, `halloween`, `new_year`, `ramadan_eid`)
- [x] **B.13 Scalable Realism & Performance Budgets**: Tier-gated soft shadows, believable materials, faked AO, reflections, light shafts, subtle DOF and grain (`Low` = clean stylized, `Medium` = more, `High` = richest, `Auto` steps down); explicit per-tier budgets (`drawCalls`, `triangles`, `particles`); live FPS and tier readout in Settings → Robot; automated headless Chrome software-rendering budget test at `Low`
- [x] **B.14 Room Builder Studio Tab**: Catalog of >= 100 procedural props across 13 categories (`furniture`, `plants`, `tech`, `art`, `lights`, `toys`, `windows`, `rugs`, `wall_decor`, `food_drinks`, `instruments`, `sports`, `books`) with category filter and search; placement with snapping to `floor`, `wall`, `shelf`, `ceiling` slots; move, rotate, scale, recolor, duplicate, delete; undo/redo; wall/floor/ceiling/window procedural styles & colors; lighting rigs; per-prop animation & interaction switches; save up to 24 custom rooms, export/import `.robot-room.json` (versioned), and per-character room persistence
- [x] **B.15 Camera & Photo Mode**: Camera shots and presets (`close`, `medium`, `wide`, `orbit`, `dolly`, `rack_focus`, `handheld`, `security_cam`, `cinematic`), saveable custom camera moves, Photo Mode saving PNG (optionally transparent background), automatic look & room thumbnails, exact green/blue screen preservation, and steady filming mode
- [x] **Docs, i18n & Visuals**: 100% EN/DE/AR translation parity (`npm run i18n`), unit/integration/e2e/a11y tests passing, regenerated Studio/looks/places screenshots, and updated `README.md`, `CHANGELOG.md`, and `docs/release-0.7/DECISIONS.md`

- [x] **W.1 Shared Whiteboard Document Model & Vector Schema**: Universal vector document model (`src/js/whiteboard/model.mjs`, `server/whiteboard-model.js`): strokes (with pressure, velocity, smoothed bezier paths), shapes (rectangle, rounded rect, circle/ellipse, triangle, diamond, star, polygon, line, arrow, double arrow, curved connector with anchor ports), text (rich typography, styled fonts, handwriting styles, KaTeX math formulas, code blocks with syntax highlighting), sticky notes (with colors, folded corner, tilt), checklists, tables (grid cells, headers, editable text), images (local data URLs/blobs, aspect fit/fill), diagrams (Mermaid flowchart/sequence/state/class or compact structured json syntax), stickers and emoji; per-item metadata (z-index/layer, id, timestamps `t0`, `duration`, stroke progression points) allowing real-time replay and animated stroke-by-stroke robot drawing; versioned schema (`version: 1`).
- [x] **W.2 Storage, Migration & Server API**: Local storage in `~/.config/friends/whiteboards/` (or `FRIENDS_DATA_DIR/whiteboards/`) with metadata index (`index.json`), individual JSON files per board `<id>.json`, multi-page support per board (`pages: []`), version history snapshots with restore capability, and cleanup/size limit enforcement; REST API in `server/server.js` and `server/whiteboard.js` (`GET /api/whiteboards`, `POST /api/whiteboards`, `GET /api/whiteboards/:id`, `PUT /api/whiteboards/:id`, `PATCH /api/whiteboards/:id`, `DELETE /api/whiteboards/:id`, `POST /api/whiteboards/:id/duplicate`, `POST /api/whiteboards/:id/export`, `GET /api/whiteboards/active`); backup integration in `scripts/backup.js` and `server/backup.js`; safe migrations for legacy storage.
- [x] **W.3 Robot 3D Board Prop & Room Integration**: Procedural 3D board prop (`src/js/robot/places/whiteboard3d.js`) placed in the robot's room across all places and available in Room Builder (`room-catalog.mjs`); multiple switchable board styles (`whiteboard`, `chalkboard`, `glass board`, `cork board`, `easel`, `flip chart`, `wall-sized screen`); dynamic canvas texture reflection in Three.js (`CanvasTexture` with dirty update flags, offscreen rendering, lightweight on Low quality flat mode); size, position, yaw/tilt configured per place and dockable in chat dock / voice mode / filming mode.
- [x] **W.4 Robot Arm Writing, Pointing & Erasing Choreography**: Robot physical motion system in `src/js/robot/animator.mjs` and `src/js/robot/director.mjs`: picking up marker/chalk prop with arm, extending hand to stroke coordinates on the 3D board, following stroke trajectories in sync with stroke progression, stepping back to admire the board, pointing gestures (`point_at` region, left, right, specific item or sticky note) while talking, erasing gestures with felt cloth / eraser block, and tidying up markers; procedural WebAudio sound effects (`src/js/robot/sound.js`): marker squeaks/strokes, chalk scuffs/taps, and cloth eraser sweeps.
- [x] **W.5 AI Whiteboard Tools & Fenced Block Fallback**: AI tools in `server/tools.js` and `server/whiteboard.js` (`whiteboard_write_text`, `whiteboard_draw_shape`, `whiteboard_draw_diagram`, `whiteboard_add_sticky`, `whiteboard_add_checklist`, `whiteboard_add_table`, `whiteboard_add_image`, `whiteboard_draw_freehand`, `whiteboard_highlight`, `whiteboard_point_at`, `whiteboard_erase_region`, `whiteboard_clear`, `whiteboard_new_page`, `whiteboard_read_board`, `whiteboard_snapshot`); compact essential subset in `ESSENTIAL` toolset for small local models; fenced markdown fallback parser (` ```whiteboard ... ``` `) in `src/js/whiteboard/parser.mjs` and `server/whiteboard-parser.js` so models without function-calling can safely manipulate the board.
- [x] **W.6 Handwriting, Multilingual (German Umlauts & Arabic RTL), Math & Code**: Writing styles (`marker`, `chalk`, `neat print`, `cursive`, and `plain`); full typography support for German umlauts (ä, ö, ü, ß) and Arabic right-to-left joined cursive script (`Noto Sans Arabic` with correct text shaping; progressive stroke reveal without breaking Arabic glyph ligatures); Math rendering with KaTeX and code syntax highlighting with line numbers.
- [x] **W.7 Interactive User Canvas & Drawing Suite**: High-performance HTML5 2D Canvas engine (`src/js/whiteboard/canvas.js`): hardware-accelerated offscreen caching, smooth variable-width strokes with stylus pressure support (PointerEvent pressure/tilt), highlighter blending mode (`multiply`/translucent); tools: Pen, Highlighter, Eraser (stroke & area), Shapes (rect, rounded rect, ellipse, triangle, diamond, star, polygon, line, directional arrow, curved connector), Text, Sticky note, Checklist, Table, Image import, Selection (lasso & bounding box marquee, move, resize with handle snapping, rotate), Group/ungroup, Layer ordering; canvas backgrounds: Plain, Grid, Ruled lined, Dot grid, Isometric/Graph, Music staff; Pan, Zoom, Infinite canvas option, Snap-to-grid & object alignment guides, Multi-level Undo & Redo stack; complete keyboard accessible alternatives for drawing and editing.
- [x] **W.8 Human-Robot Collaboration & First-Class Actions**: Bi-directional shared state between user and robot in real time; visual presence indicators; first-class collaboration actions: "Show your work", "Explain this on the board", "Draw the plan", "Clean up my sketch into a tidy diagram", and interactive games (tic-tac-toe, hangman, draw-and-guess); protection & etiquette: "Ask before drawing over user work", auto-hide board when empty, configurable writing speed, and per-turn stroke limits.
- [x] **W.9 Multi-View UI (Full View, Docked Side Panel, Floating Pop-Out)**: Three UI presentations (`src/js/whiteboard/ui.js`): full-screen dedicated view (`#view-whiteboard`) accessible via topbar and sidebar navigation, dockable side panel alongside Talk/Chat and Missions, and detachable floating pop-out window; multi-page manager with thumbnail strip; multi-board browser (board switcher, per-chat board, per-character board, per-mission board, search, tags, and built-in templates: Blank, Weekly Planner, Brainstorming, Pros & Cons, Mind Map, Timeline, Kanban, Flowchart, Math Lesson).
- [x] **W.10 Export, Vault Integration & Telegram Sharing Hooks**: Multi-format exporter: PNG (with optional transparent background), SVG vector export, PDF multipage export, and JSON document backup; one-click copy image to clipboard and "Save to Notes Vault" as Markdown note or embedded image attachment; Telegram sharing extension point (prepared for Workstream 4 integration).
- [x] **W.11 Whiteboard Settings & Privacy Protection**: Settings → Whiteboard section: master switch, per-character defaults, room board look, writing style and speed, marker colors, recording/filming display toggle, mission tool permissions, and auto-hide; full Private mode enforcement (zero network calls), board text and image payloads registered in "what could leave this computer" telemetry, sensitive data scrubbing (API keys, credentials, credit cards, emails, phone numbers) before cloud AI transmission, and strict SVG/image sanitization via DOMPurify.
- [x] **W.12 Comprehensive Testing Suite, A11y & Documentation**: Pure unit tests (`test/whiteboard-model.test.js`, `test/whiteboard-parser.test.js`, `test/whiteboard-storage.test.js`), HTTP tests (`test/whiteboard-api.test.js`), robot tests (`test/robot-whiteboard.test.js`), browser/a11y tests (`scripts/a11y.js` / e2e), 100% EN/DE/AR translation parity (`npm run i18n`), updated `CHANGELOG.md`, `README.md`, and `docs/release-0.7/DECISIONS.md`.
